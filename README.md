# РАБОТНИ ОБЯВИ

Идеята за това приложение ми дойде тъй като съм имал нужда от майстори вкъщи. Приложението служи за публикуване на работни обяви., кой какво може да направи, в колко часа може да дойде.

## Структура


Следващите папки са отделени в отделен namespace - GCommon
- Captions - съдържа имената по полетата за входни данни
- Contracts - задава методите, които се изпълняват по контролерите
- Data - класовете от Entity Framework. Улесних си работата чрез Database-First подход
- ExtensionAttributes - потребителски атрибути за валидация. В случая има само валидация за снимка. Качваният файл за работник трябва да е не повече от *200Кб* и от тип *jpeg*
- ExtensionMethods - форматиране, обединение на полета. Много удобно става и чисто
- ExtensionTagHelper - потребителски tag helper. В случая само оформление като многоредов текст - знакът за нов ред преминава като p таг
- Models - моделите, които се показват в страниците
- Services - истинското изпълнение на интерфейсите
- ValidationMessage - съобщенията за валидация при запис към базата.

Контролерите и изгледите разчитат на този namespace.

## Инсталация
- Базата данни се казва MEISTER. Превод от немски - означава Майстор.
- Отваряте си проекта във Visual Studio 2022.
- Работим със .NET Core 9.0
- В папка Captions, файл export_sql.txt съдържа последно попълнените данни в базата. Може те да се ползват
- Отваряте appsettings.json и променяте само стойността на Server с името на локалния database server. Всичко друго остава непроменено.

"ConnectionStrings": {
    "DefaultConnection": "Server=**[име на сървъра]**;Database=MEISTER;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=true",
    "meister": "Server=**[име на сървъра]**;Database=MEISTER;Trusted_Connection=True;TrustServerCertificate=True"
  }


## Описание на базата данни
### Таблица WORK_START_HOURS
Показва началните работни часове. 
Полетата са 
1. номер **ID**
2. час  **SHOUR**
3. минута **SMINUTE**

------------
### Таблица WORKER
Показва кой ще работи
Полетата са
1. номер **ID**
2. име **FNAME**
3. фамилия **LNAME**
4. телефон **PHONE**
5. емейл **EMAIL**
6. снимка **PHOTO** Тук ограничението на файла е до *200 кб* и тип на файла *jpeg*. Взема се mime типа на качвания файл

------------


### Таблица TAX_WAGE
Показва начините на таксуване - на ден/линеен метър и т.н
Полетата са
1. номер  **ID**
2. име **CAPTION**

------------

### Таблица WORK_CATEGORY
Показва какво се прави - мазилка, боядисване и т.н
Полетата са
1. номер **ID**
2. име **CAPTION**

------------

### Таблица WORKER_CAPABILTY
Показва връзка между работник и способностите му
Полетата са
1. номер **ID**
2. номер на работник **WORKER_ID**
3. номер на категория труд **WORK_CATEGORY_ID**
4. цена **PRICE**. Тук цената е фиксирана към труда, а не към обявата. Идеята е че продаваме труда си, а не нещо временно
5. начин на плащане **TAX_WAGE_ID**

------------
### Таблица DECLARE_WORKER_FREE
Показва наличните обяви
Полетата са
1. номер **ID**
2. начален час **HOUR_ID**
3. какво ще се прави **WORKER_CAPABILITY_ID**
4. текста на обявата **AD_TEXT**
5. за кой ден ще се работи **WATCH_DATE**
